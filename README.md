# 📚 Serverless Data Management API

A serverless CRUD-based API application for student data management using AWS S3, API Gateway, Lambda, and DynamoDB with a static frontend and scalable cloud-native backend.

## 🏗️ Architecture

- **Frontend**: Static website hosted on Amazon S3
- **API Layer**: AWS API Gateway with request validation and CORS
- **Backend**: AWS Lambda functions for serverless compute
- **Database**: DynamoDB for student data storage
- **Communication**: RESTful APIs for structured client-server interaction

## ✨ Features

- Complete CRUD operations for student data management
- Create, retrieve, update, and delete workflows
- Request validation and CORS configuration
- Secure and reliable API access
- Scalable, cost-optimized architecture

## 📋 Setup

1. Create DynamoDB table for student data storage
2. Deploy Lambda functions for CRUD operations
3. Configure API Gateway with RESTful endpoints
4. Set up request validation and CORS policies
5. Upload static frontend files to S3 bucket
6. Connect frontend to API Gateway endpoints

## 🏆 Benefits

- Serverless architecture with automatic scaling
- Cost-optimized pay-per-use model
- Cloud-native backend solution
- Structured client-server communication
- High availability and reliability
